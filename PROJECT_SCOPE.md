# Siddeeq & A'ishah Institute: Project Scope

Demo rebuild of the institute's website, built with permission.
Fake data only. Not used by the institute.

## Stack
Java 17, Spring Boot, Maven, Spring Data JPA, PostgreSQL, React + TypeScript (Vite)

## Main data
- Program (includes branch: Siddeeq or A'ishah)
- Student
- Registration
- Payment status

## Roles
- Admin
- Teacher
- Student/Parent

## V1 features
1. Program list pulled from the database
2. Online registration
3. Admin approves, waitlists, or rejects registrations
4. Admin marks payment as received
5. Registration closes when a program is full or past its deadline

## Public pages
Home, About, Programs, A'ishah Institute, Events, Contact

## Later
Youth Corner, Multimedia

## Done means
Someone can open the live link, register, log in as a demo admin,
and approve that registration.
